# Spain Football Team Performance Analysis Dashboard (World Cup 2026)

## 📌 Project Overview
This project presents a highly interactive and insightful data analysis dashboard built using **Power BI** to evaluate the squad depth and player performance of the **Spain Football Team (La Roja)** ahead of the World Cup 2026. The dataset incorporates real-life performance statistics from the 2025-26 multi-competition season, focusing on four key operational areas: Forward Efficiency, Midfield Mastery, Defensive Art, and Goalkeeping Strength.

---

## 📊 Dashboard Pages & Insights

### 1. Forwards Analysis
* **Focus:** Measuring clinical execution, dynamic wings play, and goal-scoring efficiency (featuring key data points for world-class emerging talents like Lamine Yamal and Nico Williams).
* **Key Visuals:** Balanced Goal vs. Assist clustering alongside a customized Donut Chart displaying Penalty Success Rates mapped across accurate percentages.

### 2. Midfielders Analysis
* **Focus:** Tracking possession retention, progressive passing efficiency, and high-tempo tackle-to-interception cycles in the central zones.
* **Key Visuals:** Dual-axis comparative charts displaying individual passing accuracies (%) against total progressive yards.

### 3. Defenders Analysis
* **Focus:** Evaluating aerial duel dominance, transitional tackle mechanics, and backline structural integrity.
* **Key Visuals:** Trend lines mapping Aerial Won (%) and clustered bar segments tracking individual defensive contributions.

### 4. Goalkeeper Analysis
* **Focus:** Visualizing shot-stopping metrics, clean sheet volume, and high-pressure launching accuracy (%).
* **Key Visuals:** Advanced **PSxG +/-** metrics coupled with clean sheet ratios to evaluate performance trends of Unai Simón and David Raya.

---

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** Dashboard design, data visualization, and UI implementation.
* **Microsoft Excel:** Data storage, restructuring, and source data management (sourced via FBRef).
* **DAX (Data Analysis Expressions):** Customized measures for precise performance metrics.
